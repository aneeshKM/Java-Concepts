- [ ] `DataTypesDemo.java` — Use all primitive types, reference types, wrappers, boxing, and unboxing.

- [ ] `OperatorsDemo.java` — Exercise arithmetic, relational, logical, bitwise, and short-circuit operators.

- [ ] `MethodsDemo.java` — Use parameters, return values, varargs, scope, and a small recursive method.
- [ ] `PassByValueDemo.java` — Compare primitive updates, object mutation, and reference reassignment.
- [ ] `InputOutputDemo.java` — Read input with Scanner, convert values, and handle invalid input.
