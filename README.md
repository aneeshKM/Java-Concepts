# Java Concepts Revision Map

A long-term Core Java revision folder.

## How to use this folder

1. Work through the numbered chapters.
2. Study each required theory item and keep your explanations in the lesson's `README.md`, which starts empty for theory notes.
3. Create the listed programs inside the chapter's `code/` directory. Filenames are suggestions; use supporting classes or packages where needed.
4. Check an item only after you can explain it or compile, run, and verify the program yourself.
5. Complete the revision checks without referring to your notes; update the progress table.
